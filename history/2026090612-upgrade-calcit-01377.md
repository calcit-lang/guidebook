# Upgrade to Calcit 0.13.77

## 中文

- 将 Calcit 与 `@calcit/procs` 对齐到 0.13.77，并升级已发布的 Respo、Lilac、Memof 与 docs-workflow 0.0.26 依赖链。
- 保持 `calcit.cirru` 为唯一源码 Snapshot，迁移 operation 判断到 Enum pattern matching。
- 升级 Node 24 / Yarn 4 / Vite 8.2.2，固定 CI Actions SHA，并为 mdBook 下载增加 SHA-256 校验。
- 增加动态方法零容忍与原生质量基线门禁。

## English

- Align Calcit and `@calcit/procs` at 0.13.77 and upgrade the released Respo, Lilac, Memof, and docs-workflow 0.0.26 dependency graph.
- Keep `calcit.cirru` as the only source snapshot and migrate operation checks to Enum pattern matching.
- Upgrade Node 24 / Yarn 4 / Vite 8.2.2, pin CI Action SHAs, and verify mdBook downloads with SHA-256.
- Add a zero dynamic-method policy and a native quality baseline gate.
